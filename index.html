How it worksPick the PR date to see that day's PRs (or tick All dates for the newest 6000). Type in any cell: the row is saved automatically a moment after you stop typing. Delete: click the row number (Shift = a range, the # heading = all) and press Delete selected. Like Excel: arrow keys / Enter move between cells; drag (or Shift+click, Shift+Up/Down) selects a block; Ctrl+C copies it; Ctrl+V pastes a small block at the cell (or one value into all selected cells); Delete clears the selected cells; Ctrl+D fills down, Ctrl+R fills right; Ctrl+Z / Ctrl+Y undo / redo. Locked cells are skipped. Pending issue / replacement / return: tap that number in the Summary to fill firm, driver and dates on cards. New PRs: type in the empty rows at the top, or copy rows from Excel and press Ctrl+V in any cell (up to 300 rows; use the Paste from Excel button for more). A new row is saved by itself once Workshop, Division, Capacity, PR NO and PR DATE are filled (the Save button saves it at once). PR NO, PR DATE and Workshop are compulsory. Workshop, Division, Substation, Feeder, Place, Capacity, Complain no, PR NO and PR DATE of a saved PR are locked; to correct them delete the row and add it again. Choose the firm DUPLICATE/WRONG PR for a wrong or duplicate PR: the issue date, driver name / mobile, replacement and return dates are cleared and locked (only the Remark can be written). Paste from Excel (button) adds many PRs at once: a PR that already exists only gets its empty cells filled.
